# Day 08 - AI Job Application Tracker

## What I built
A simple AI job application tracker using multiple Python files.

## Features
- Create a job application
- Show application information
- Update application status
- Validate empty input
- Reject numeric-only text input
- Use menu-based program flow

## Concepts practiced
- Python class
- Object attributes
- Object methods
- Multi-file project structure
- Importing modules
- Input validation
- While loop
- If/elif/else

## Files
- `application.py` - contains the JobApplication class
- `input_utils.py` - contains input validation functions
- `main.py` - runs the main program
