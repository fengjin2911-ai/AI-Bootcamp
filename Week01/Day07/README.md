# Day 07 - Error Handling Utilities

## Overview

This project practices error handling and input validation in Python.

The goal is to make programs more robust by preventing crashes when users enter invalid input, such as text instead of numbers or menu choices outside the allowed range.

## Topics Practiced

- `try`
- `except`
- `ValueError`
- Input validation
- While loops
- Utility functions
- Safe user input
- Menu validation
