# Day 06 - Simple Model Monitor

## Overview

This project practices Python modules and imports by separating monitoring logic into another file.

The program checks GPU usage and request load for a simple AI inference service.

## Topics Practiced

- Python modules
- Importing functions from another file
- Separating logic from the main program
- User input
- Conditional statements
- Running Python files from the command line
